DAFCLIPS Uploader – Privacy Policy

Effective October 17, 2026. DAFCLIPS Uploader is a personal tool run by the owner of the DAFCLIPSTV channel. It uploads his own gameplay videos to YouTube channels he owns (e.g. DAFCLIPSTV). It has no other users.

YouTube API Services

This tool uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. See also the Google Privacy Policy.

What data is accessed and stored

  • An OAuth refresh token for the authorizing channel owner's account. It is stored only on the owner's private machine, readable only by the owner's user account.
  • The channel ID and title, plus the IDs, upload status and schedule of videos the tool uploaded.

The tool does not collect data about other YouTube users. It does not share or sell any data and serves no ads. It does not use cookies or collect data from visitors' devices, and this website sets no cookies.

How data is used

Data is used only to upload, schedule and check the owner's own videos and to set their thumbnails and playlists.

Retention, deletion and revocation

Upload records are kept only as long as needed to manage the owner's videos. Stored tokens and records are deleted on request or when the tool is retired. You can revoke the tool's access at any time at https://security.google.com/settings/security/permissions.
